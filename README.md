# 🏺 Ловец-Кинцуги — радар корпоративных клиентов KingTsugi

Бот-продажник для мастер-классов по кинцуги: раз в день присылает в Telegram
несколько лидов (event-агентства и компании Москвы) с **готовым персональным
КП** — нейросеть пишет письмо под каждого адресата, с учётом сегмента:
агентствам предлагает партнёрство (формат в их каталог), HR компаний —
тимбилдинг напрямую. Одна кнопка — и КП улетает на почту.

Крутится целиком на GitHub Actions — компьютер не нужен. Основа —
[lovec-fpv](https://github.com/safonovich/lovec-fpv), логика та же:
исходящий outreach по базе, отправка только по кнопке.

## Как это работает

1. `data/leads.json` — база лидов (стартовые 12 уже внутри: 9 event-агентств
   из заметок + 2 компании + 1 тестовый лид на свою почту).
2. Workflow **Collect** (запуск вручную) обходит сайты и достаёт
   email/телефон/Telegram.
3. Каждый день в ~10:00 МСК бот берёт 3 новых лида из базы, тянет их сайт,
   генерирует персональное КП и присылает карточки в Telegram.
4. Кнопки под карточкой:
   - **📧 Отправить на email** — письмо уходит с твоей почты (текст ровно тот,
     что в карточке). Срабатывает при ближайшем прогоне, до ~15–25 мин.
   - **👎 Пропустить** — лид помечается и больше не предлагается.
   - **📣 Канал в TG / 💬 WhatsApp** — быстрый переход (в WhatsApp текст
     КП подставится сам).

## Запуск с нуля (≈30 минут)

1. **Склонируй репозиторий** себе на GitHub. Делай **публичным** —
   у публичных Actions бесплатны без лимита.
2. **Бот уже создан** — токен в секрет. ⚠️ Напиши боту любое сообщение
   (Start), иначе он не сможет тебе писать.
3. **Узнай свой ID**: @userinfobot.
4. **Пароль приложения Gmail**: myaccount.google.com → Безопасность →
   двухэтапная проверка → Пароли приложений.
5. **Секреты** (Settings → Secrets and variables → Actions):

| Секрет | Что это |
|---|---|
| `TG_BOT_TOKEN` | токен бота из BotFather |
| `TG_CHAT_ID` | твой Telegram ID |
| `SMTP_USER` | safpelerin@gmail.com |
| `SMTP_PASS` | пароль приложения Gmail (не обычный пароль!) |
| `LLM_API_KEY` | ключ нейросети (ChadGPT / OpenRouter / Claude — см. [llm] в config.toml) |

6. **Проверь `kt/config.toml`**: цены, телефон, тексты — всё правится там.
7. **Собери контакты**: Actions → **Collect** → Run workflow.
8. **Первый запуск**: Actions → **Kintsugi** → Run workflow. Дальше — само.

Первая карточка — «Тест KingTsugi (SAF)»: КП придёт на твою же почту.
Ответь на него со своего ящика — проверишь переговорный контур целиком.

## База лидов

- **Сегменты**: `event` (агентства — партнёрство) и `company` (HR — напрямую).
  От сегмента зависит текст КП и переговоров.
- **Пополняется**: workflow **Discover** по понедельникам тянет event-агентства
  Москвы из OpenStreetMap. Покрытие там скромное, поэтому основной канал —
  руками: открыть `data/leads.json` на GitHub → карандаш → дописать → Commit.
  Достаточно `id`, `name`, `site`, `segment` — остальное добьёт Collect.
- Где брать лиды пачками: каталоги event-агентств, career.habr.com/companies,
  hh.ru (фильтр Москва + IT/финтех/реклама → почты hr@/career@),
  TG-каталоги HR-сообществ (huntflow.media/more-telegram).
- Статусы: `new` → `offered` (карточка выдана) → `sent`/`skipped`.
  После ответа бот сам ставит `replied`.

## Переговоры: что происходит после отправки КП

- **Ответили** → бот видит письмо (IMAP, каждые ~15 мин), нейросеть пишет
  черновик и присылает карточку: их письмо + черновик + кнопки
  **📤 Отправить ответ** / **✏️ Сам отвечу**. Ничего не уходит без кнопки.
- **Рамки**: цены только из конфига, без скидок и обещаний дат; цель —
  дата/размер группы, созвон или отправка презентации. Договор, юр. вопросы
  и негатив — бот не отвечает, зовёт тебя.
- **Не ответили 4 дня** → одно вежливое напоминание (само). Второго не будет.

## Этика рассылки

- 3 письма в день — точечный outreach, не спам-пушка. Не задирай `daily_leads`.
- Правило из заметок: не продавать, а приглашать посмотреть формат.
  К письму стоит добавлять 2–3 фото работ — бот шлёт текст, фото можно
  досылать вручную при ответе.
- Просят больше не писать — ставь `skipped`.

## Нейросеть

`[llm]` в config.toml: ChadGPT (по умолчанию, подписка), любой
OpenAI-совместимый API (OpenRouter и т.п.) или Claude. Без ключа тоже
работает: КП собирается из шаблона, ответы пересылаются без черновиков.
